# Assets

This folder is reserved for safe portfolio assets such as exported diagrams, cover images, or sanitized presentation graphics.

## Allowed Assets

- Exported Mermaid diagrams.
- Sanitized screenshots.
- Portfolio cover graphics.
- Demo-only workflow illustrations.

## Disallowed Assets

- `.env` files, tokens, or `service-account.json` credentials.
- Browser profile data (`.linkedin-browser-profile/`), cookies, or session state.
- The real `Connections.csv` export or any real contact/campaign data.
- Server logs (`server.stdout.log`, `server.stderr.log`) — these can contain real LinkedIn profile URLs and Google API payloads.
- Raw source code copied from the implementation repository.
